# OpenLamp State (OLS) — moved

This contract now lives in its own repository:
**https://github.com/openlamp/openlamp-spec-state**

It was here until 2026-09-20, which was the defect: a spec hosted inside one of
the things that implement it is that implementation's documentation, and every
other implementation has to link into this tree to state what it conforms to.

This engine implements OLS v2.0. The document, its history and its version now
sit beside their sibling [openlamp-spec-midi](https://github.com/openlamp/openlamp-spec-midi).
